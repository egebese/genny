# Phases

Each phase has one job and a definition of done you can run. A phase is finished
when its exit criteria pass, not when its code is written.

| Phase | Subject | Milestone |
|---|---|---|
| [0](phase-0.md) | Foundation: monorepo, database, RLS, CI, docs | M0 |
| [1](phase-1.md) | Image studio end to end, BYOK | M1 |
| [2](phase-2.md) | SaaS: accounts, credits, Stripe, webhooks | M2 |
| [3](phase-3.md) | Video and audio | M3 |
| [4](phase-4.md) | Admin panel | M4 |
| [5](phase-5.md) | Landing, blog, SEO | M5 |
| [6](phase-6.md) | Hardening: a11y, performance, observability | M6 |

Work that jumps ahead usually waits, not because it is bad but because the
foundation it needs is not there yet.
